# 🔔 School AOD — ระบบอ๊อดโรงเรียนอัตโนมัติ

**ระบบกริ่ง/ออดและเสียงตามสายโรงเรียน — ประกาศด้วยเสียง AI 3 ภาษา (ไทย/English/中文) ควบคุมผ่านมือถือได้ทุกที่**

*School Automatic On-Duty Bell & Multilingual PA System — Desktop + Realtime Remote Control*

</div>

---

## 📖 เกี่ยวกับโปรเจกต์

**School AOD** คือโปรแกรมตั้งเวลากริ่ง/ออดโรงเรียนอัตโนมัติ ทำงานบนคอมพิวเตอร์ที่ต่อกับเครื่องเสียงของโรงเรียน
สามารถตั้งตารางเวลาแต่ละคาบ ขานเวลาเป็นเสียงภาษาไทยอัตโนมัติ อ่านชื่อกิจกรรมในแต่ละคาบ เล่นเพลงชาติ/เสียงประกอบ
และ **ควบคุมจากมือถือ/แท็บเล็ตที่ไหนก็ได้** รวมถึง **พูดประชาสัมพันธ์สดผ่านมือถือให้ออกที่โรงเรียนแบบเรียลไทม์**

---

## ✨ ความสามารถเด่น

- 🕒 **ตั้งตารางออดอัตโนมัติ** — กำหนดเวลาแต่ละคาบ เลือกวันในสัปดาห์ เปิด/ปิดรายคาบได้
- 🌐 **ประกาศ 3 ภาษาแบบเสียงตามสายสากล** *(ใหม่ v2.0)* — ติ๊กเลือก ไทย / English / 中文 จัดลำดับการอ่านได้ (▲▼) และกำหนดจำนวนรอบทวนแต่ละภาษา
- 🤖 **เสียง AI คุณภาพผู้ประกาศ** *(ใหม่ v2.0)* — เลือกเสียงผู้หญิง / ผู้ชาย / เด็กผู้หญิง / เด็กผู้ชาย หรือเลือกเสียงอื่น ๆ รายภาษา ปรับความเร็วได้
- ✍️ **พิมพ์ไทยครั้งเดียว แปลอังกฤษ/จีนให้อัตโนมัติ** *(ใหม่ v2.0)* — แก้คำแปลเองได้
- 📴 **ใช้งานออฟไลน์ได้** *(ใหม่ v2.0)* — ดาวน์โหลดเสียง AI ของทุกตารางเก็บไว้ในเครื่อง เน็ตหลุดออดก็ยังดังตรงเวลา
- 📢 **ศูนย์ประกาศเสียงตามสาย** *(ใหม่ v2.0)* — พิมพ์ข้อความแล้วประกาศทันที มีข้อความสำเร็จรูป บันทึกเพิ่มเองได้
- 🔄 **อัปเดตโปรแกรมในตัว** *(ใหม่ v2.0)* — แจ้งเตือนเวอร์ชันใหม่ กดอัปเดตได้ทันที ไม่ต้องติดตั้งใหม่ ข้อมูลเดิมอยู่ครบ
- 🗣️ **ขานเวลาอัตโนมัติ** — "ขณะนี้เวลา ... นาฬิกา ... นาที" ในทุกภาษาที่เลือก + อ่านชื่อกิจกรรมในคาบนั้น
- 🔔 **เสียงติ่งต่องหน้า/ท้าย** — เปิด/ปิดแยกกันได้อิสระ + เสียงประกอบ/เพลงชาติต่อท้าย
- 🎵 **เสียงติ่งต่อง 10 แบบ × 3 ความยาว** *(ใหม่ v2.3)* — คลาสสิก, สนามบิน, สถานีรถไฟ, หอนาฬิกา, กระดิ่งโรงเรียน, ระนาด, เปียโน, คริสตัล, ฮาร์ป, ประกาศด่วน แต่ละแบบมี สั้นกระชับ / ปานกลาง / ยาว ตั้งค่าเริ่มต้นหรือเลือกรายคาบได้ (มีปุ่มฟังตัวอย่าง)
- 📱 **รีโมทผ่านมือถือ (PWA)** — ติดตั้งลงจอโฮมเหมือนแอป ใช้ได้ทั้ง Android / iOS
- 🎙️ **ประชาสัมพันธ์สดแบบเรียลไทม์** — กดพูดผ่านมือถือ เสียงออกที่โรงเรียนทันที (walkie-talkie) พร้อมระบบ Drop เสียงให้ไมค์มาก่อน
- 🌐 **ลิงก์สาธารณะอัตโนมัติ** — สร้างลิงก์ HTTPS ให้เองด้วย Cloudflare Tunnel ไม่ต้องตั้งค่าเราเตอร์
- 🎵 **จัดการไฟล์เสียง** — เพิ่ม/ลบ/เปลี่ยนชื่อ/ฟัง เก็บใน Local Database (SQLite)
- 🎨 **เลือกธีมสีได้ 4 แบบ** — มาตรฐาน / สว่าง / เข้ม / ขาวดำ
- 🔐 **ระบบ PIN + เปิด/ปิดสิทธิ์พูดผ่านรีโมท** ควบคุมโดยเครื่องแม่
- 🖥️ **ทำงานเบื้องหลัง** — ย่อลง System Tray รันตลอด 24 ชม.

## 📥 ดาวน์โหลดและติดตั้ง (Windows)

1. ดาวน์โหลดไฟล์จากหน้า **[Releases](../../releases)** (หรือจากแท็บ **Actions** → artifact `SchoolAOD-Windows`)
2. แตกไฟล์ จะได้ **`SchoolAOD.exe`** และ **`cloudflared.exe`** — วางไว้โฟลเดอร์เดียวกัน (แนะนำวางบน Desktop)
3. ดับเบิลคลิก `SchoolAOD.exe`
4. รอ ~5 วินาที ลิงก์รีโมท (HTTPS) จะขึ้นในหน้า Dashboard เอง

> ข้อมูลทั้งหมด (ตารางเวลา/ไฟล์เสียง/ตั้งค่า) เก็บที่ `%APPDATA%\SchoolAOD` โดยอัตโนมัติ

## 🚀 วิธีใช้งาน (คู่มือ)

### บนเครื่องแม่ (คอมพิวเตอร์)
1. **แท็บหน้าหลัก** — ดูเวลาปัจจุบัน, ออดรอบถัดไป, สถานะเสียง AI, PIN Code และลิงก์รีโมท
2. **แท็บประกาศเสียงตามสาย** — พิมพ์ข้อความ → ติ๊กภาษา → จัดลำดับ/รอบทวน → กด **📢 ประกาศทันที**
   - กด **🌐 แปลอัตโนมัติ** เพื่อเติมภาษาอังกฤษ/จีนจากข้อความไทย
   - เลือก **ข้อความสำเร็จรูป** หรือ **บันทึกข้อความ** ไว้ใช้ซ้ำ
3. **แท็บจัดการตารางเวลา** — เพิ่ม/แก้ไขคาบ กำหนดเวลา ชื่อกิจกรรม วันในสัปดาห์ และลำดับเสียง
   - กดปุ่มในคอลัมน์ **ภาษา (ลำดับอ่าน)** เพื่อเลือกภาษาที่จะพูด สลับลำดับ และจำนวนรอบ ของแต่ละรายการได้ทันที
   - พิมพ์ภาษาไทยลงช่องอังกฤษ/จีนได้เลย ระบบแปลเป็นภาษาของช่องนั้นให้อัตโนมัติ (พิมพ์ภาษาจริงก็อ่านตามนั้น ไม่แปลทับ)
   - กด ✏️ เพื่อแก้รายละเอียดทั้งหมดของคาบ รวมถึงสไตล์เสียง (มีปุ่มทดลองฟัง)
   - ดับเบิลคลิกช่อง "เวลา" เพื่อแก้เวลาได้ทันที มีผลทันที
   - สลับสวิตช์ ติ่งต่องหน้า / ขานเวลา / ติ่งต่องท้าย / เปิด-ปิด ได้รายคาบ
4. **แท็บจัดการไฟล์เสียง** — อัปโหลด/ลบ/เปลี่ยนชื่อ/ฟังไฟล์เสียง
5. **แท็บตั้งค่า** — สไตล์เสียง AI, ความเร็ว, เลือกเสียงรายภาษา, ดาวน์โหลดเสียงไว้ใช้ออฟไลน์, ตรวจสอบอัปเดต
6. เลือก **ธีมสี** ได้ที่ปุ่มมุมขวาบน

### ลำดับเสียงเมื่อถึงเวลาออด
`🔔 ติ่งต่องหน้า → (ภาษาที่ 1 × รอบทวน) → (ภาษาที่ 2 × รอบทวน) → (ภาษาที่ 3 × รอบทวน) → 🎵 เสียงต่อท้าย → 🔔 ติ่งต่องท้าย`
แต่ละภาษาพูด "ขานเวลา + ข้อความประกาศ" ในภาษานั้น — ถ้ามีการพูดสดผ่านไมค์อยู่ ระบบให้ไมค์มาก่อนเสมอ

### ควบคุมจากมือถือ/แท็บเล็ต
1. เปิดลิงก์รีโมทใน **Safari (iOS)** หรือ **Chrome (Android)** — ต้องเป็นเบราว์เซอร์จริง ไม่ใช่ in-app
2. กรอก **PIN Code** (ดูได้จากหน้าหลักของเครื่องแม่)
3. สั่งเปิดออด / กดเล่นตามตาราง / **กดพูดประชาสัมพันธ์สด** / **พิมพ์ข้อความให้เสียง AI ประกาศหลายภาษา**
   (กดไมค์บนคีย์บอร์ดมือถือเพื่อพูดเป็นข้อความได้)

### ติดตั้งรีโมทเป็นแอป (PWA)
- **iPhone/iPad:** ปุ่มแชร์ → "เพิ่มลงในหน้าจอโฮม"
- **Android:** เมนู ⋮ → "ติดตั้งแอป"
- จะได้ไอคอนแอปกระดิ่งบนจอโฮม เปิดเต็มจอเหมือนแอปจริง

## 🔄 การอัปเดตโปรแกรม

- โปรแกรมตรวจสอบเวอร์ชันใหม่ให้อัตโนมัติเมื่อเปิดโปรแกรม และทุก 6 ชั่วโมง (ปิดได้ในแท็บตั้งค่า)
- เมื่อมีเวอร์ชันใหม่ จะมี **🔔 กระดิ่งแจ้งเตือนสีส้ม** ที่มุมขวาบน และแสดงรายละเอียดให้เลือก **อัปเดตเลย / อัปเดตทีหลัง**
- เลือกอัปเดตทีหลัง กระดิ่งจะค้างไว้ให้กดอัปเดตเมื่อไรก็ได้ — **เมื่อเป็นเวอร์ชันล่าสุดแล้ว กระดิ่งจะหายไปเอง**
- กดอัปเดต → ดาวน์โหลด → โปรแกรมปิดและเปิดเวอร์ชันใหม่เอง **ตารางเวลา ไฟล์เสียง และการตั้งค่าเดิมอยู่ครบ**
- ตรวจสอบเองได้ทุกเมื่อที่ปุ่มด้านล่างหน้าต่าง ถ้าเป็นเวอร์ชันล่าสุดแล้วจะแจ้งให้ทราบ

> ผู้ที่ใช้ v1.x หรือ v2.0.0 อยู่ ต้องดาวน์โหลด v2.1 ไปติดตั้งทับเองหนึ่งครั้ง (ระบบอัปเดตในเวอร์ชันเก่ายังมีปัญหาใบรับรอง SSL บน Windows) หลังจากนั้นอัปเดตในโปรแกรมได้เลย

## 🌐 เรื่องลิงก์สาธารณะ (ฟรี)

โปรแกรมสร้างลิงก์ HTTPS สาธารณะให้เองอัตโนมัติด้วย **Cloudflare Tunnel** (ฟรี ไม่ต้องสมัคร)
ลิงก์จะสุ่มใหม่ทุกครั้งที่เปิดโปรแกรม หากต้องการ **ลิงก์ตายตัวถาวร** ให้สมัคร [ngrok](https://ngrok.com) (ฟรี)
แล้วใส่ลิงก์ในไฟล์ `config.json` ช่อง `"remote_domain"`
