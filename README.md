# 🔔 School AOD — ระบบอ๊อดโรงเรียนอัตโนมัติ

**ระบบกริ่ง/ออดโรงเรียนอัตโนมัติ ขานเวลาเป็นภาษาไทย ควบคุมระยะไกลผ่านมือถือได้ทุกที่**

*School Automatic On-Duty Bell System — Desktop + Realtime Remote Control*

</div>

---

## 📖 เกี่ยวกับโปรเจกต์

**School AOD** คือโปรแกรมตั้งเวลากริ่ง/ออดโรงเรียนอัตโนมัติ ทำงานบนคอมพิวเตอร์ที่ต่อกับเครื่องเสียงของโรงเรียน
สามารถตั้งตารางเวลาแต่ละคาบ ขานเวลาเป็นเสียงภาษาไทยอัตโนมัติ อ่านชื่อกิจกรรมในแต่ละคาบ เล่นเพลงชาติ/เสียงประกอบ
และ **ควบคุมจากมือถือ/แท็บเล็ตที่ไหนก็ได้** รวมถึง **พูดประชาสัมพันธ์สดผ่านมือถือให้ออกที่โรงเรียนแบบเรียลไทม์**

---

## ✨ ความสามารถเด่น

- 🕒 **ตั้งตารางออดอัตโนมัติ** — กำหนดเวลาแต่ละคาบ เลือกวันในสัปดาห์ เปิด/ปิดรายคาบได้
- 🗣️ **ขานเวลาภาษาไทยอัตโนมัติ** — "ขณะนี้เวลา ... นาฬิกา ... นาที" + อ่านชื่อกิจกรรมในคาบนั้น
- 🔔 **เสียงติ่งต่องหน้า/ท้าย** — เปิด/ปิดแยกกันได้อิสระ + เสียงประกอบ/เพลงชาติต่อท้าย
- 📱 **รีโมทผ่านมือถือ (PWA)** — ติดตั้งลงจอโฮมเหมือนแอป ใช้ได้ทั้ง Android / iOS
- 🎙️ **ประชาสัมพันธ์สดแบบเรียลไทม์** — กดพูดผ่านมือถือ เสียงออกที่โรงเรียนทันที (walkie-talkie) พร้อมระบบ Drop เสียงให้ไมค์มาก่อน
- 🌐 **ลิงก์สาธารณะอัตโนมัติ** — สร้างลิงก์ HTTPS ให้เองด้วย Cloudflare Tunnel ไม่ต้องตั้งค่าเราเตอร์
- 🎵 **จัดการไฟล์เสียง** — เพิ่ม/ลบ/เปลี่ยนชื่อ/ฟัง เก็บใน Local Database (SQLite)
- 🎨 **เลือกธีมสีได้ 4 แบบ** — มาตรฐาน / สว่าง / เข้ม / ขาวดำ
- 🔐 **ระบบ PIN + เปิด/ปิดสิทธิ์พูดผ่านรีโมท** ควบคุมโดยเครื่องแม่
- 🖥️ **ทำงานเบื้องหลัง** — ย่อลง System Tray รันตลอด 24 ชม.

## 📥 ดาวน์โหลดและติดตั้ง (Windows)

1. ดาวน์โหลดไฟล์จากหน้า **[Releases](../../releases)** (หรือจากแท็บ **Actions** → artifact `SchoolAOD-Windows`)
2. แตกไฟล์ จะได้ **`SchoolAOD.exe`** และ **`cloudflared.exe`** — วางไว้โฟลเดอร์เดียวกัน (แนะนำวางบน Desktop)
3. ดับเบิลคลิก `SchoolAOD.exe`
4. รอ ~5 วินาที ลิงก์รีโมท (HTTPS) จะขึ้นในหน้า Dashboard เอง

> ข้อมูลทั้งหมด (ตารางเวลา/ไฟล์เสียง/ตั้งค่า) เก็บที่ `%APPDATA%\SchoolAOD` โดยอัตโนมัติ

## 🚀 วิธีใช้งาน (คู่มือ)

### บนเครื่องแม่ (คอมพิวเตอร์)
1. **แท็บหน้าหลัก** — ดูเวลาปัจจุบัน, ออดรอบถัดไป, PIN Code และลิงก์รีโมท
2. **แท็บจัดการตารางเวลา** — เพิ่ม/แก้ไขคาบ กำหนดเวลา ชื่อกิจกรรม วันในสัปดาห์ และลำดับเสียง
   - ดับเบิลคลิกช่อง "เวลา" เพื่อแก้เวลาได้ทันที มีผลทันที
   - สลับสวิตช์ ติ่งต่องหน้า / ขานเวลา / ติ่งต่องท้าย / เปิด-ปิด ได้รายคาบ
3. **แท็บจัดการไฟล์เสียง** — อัปโหลด/ลบ/เปลี่ยนชื่อ/ฟังไฟล์เสียง
4. เลือก **ธีมสี** ได้ที่ปุ่มมุมขวาบน

### ควบคุมจากมือถือ/แท็บเล็ต
1. เปิดลิงก์รีโมทใน **Safari (iOS)** หรือ **Chrome (Android)** — ต้องเป็นเบราว์เซอร์จริง ไม่ใช่ in-app
2. กรอก **PIN Code** (ดูได้จากหน้าหลักของเครื่องแม่)
3. สั่งเปิดออด / กดเล่นตามตาราง / **กดพูดประชาสัมพันธ์สด**

### ติดตั้งรีโมทเป็นแอป (PWA)
- **iPhone/iPad:** ปุ่มแชร์ → "เพิ่มลงในหน้าจอโฮม"
- **Android:** เมนู ⋮ → "ติดตั้งแอป"
- จะได้ไอคอนแอปกระดิ่งบนจอโฮม เปิดเต็มจอเหมือนแอปจริง

## 🌐 เรื่องลิงก์สาธารณะ (ฟรี)

โปรแกรมสร้างลิงก์ HTTPS สาธารณะให้เองอัตโนมัติด้วย **Cloudflare Tunnel** (ฟรี ไม่ต้องสมัคร)
ลิงก์จะสุ่มใหม่ทุกครั้งที่เปิดโปรแกรม หากต้องการ **ลิงก์ตายตัวถาวร** ให้สมัคร [ngrok](https://ngrok.com) (ฟรี)
แล้วใส่ลิงก์ในไฟล์ `config.json` ช่อง `"remote_domain"`
