========================================================
  ระบบอ๊อดโรงเรียนอัตโนมัติ - School AOD
  วิธีใช้งานอย่างย่อ
========================================================

[ การเริ่มใช้งาน ]
1. วางไฟล์ SchoolAOD.exe และ cloudflared.exe ไว้โฟลเดอร์เดียวกัน
   (แนะนำวางบน Desktop ไม่ต้องติดตั้ง)
2. ดับเบิลคลิก SchoolAOD.exe
3. โปรแกรมจะเปิดหน้าจอควบคุม และสร้างลิงก์รีโมทให้อัตโนมัติ

[ ควบคุมจากมือถือ/แท็บเล็ต ]
- ดูลิงก์และรหัส PIN ได้ในหน้า "หน้าหลัก (Dashboard)"
- เปิดลิงก์ในมือถือ (Safari/Chrome) กรอก PIN แล้วใช้งานได้เลย
- กด "เพิ่มลงหน้าจอโฮม" เพื่อติดตั้งเป็นแอป

[ ข้อควรรู้ ]
- ต้องเปิดโปรแกรมค้างไว้ตลอดเพื่อให้อ๊อดทำงานตามเวลา
- ปิดหน้าต่างได้ โปรแกรมจะย่อลง System Tray (มุมขวาล่าง) ทำงานต่อ
- ข้อมูลทั้งหมดเก็บที่ %APPDATA%\SchoolAOD

รองรับ: Windows 10 / 11
